# EQ Avatar

A background automation companion for **EverQuest Legends** — no injection, no memory reading, just screen reading + log awareness + honest automation. Roam and grind, run rotations, map your travels, and check in to a central client hub.

This repository hosts the **in-app updater manifest** (`latest.json`) and the **release builds**. The app checks `latest.json`, and if a newer version is listed it downloads the zip and swaps itself in place — one-click updates.

- Website: https://eqavatar.ldtlan.com/avatar/
- Fan project for the LDT clan. Not affiliated with or endorsed by the makers of EverQuest or EverQuest Legends. Use responsibly and at your own risk.

## Releases

Builds are produced by CI on a version tag (`vX.Y.Z`) and attached to a GitHub Release; `latest.json` is updated to point at the newest zip.
